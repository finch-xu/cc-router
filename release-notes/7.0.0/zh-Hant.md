這是一個大版本：新增並預設啟用「簡潔」主題，全面改版即時路由、請求紀錄、訂閱管理與資料統計四大核心頁面；新增自訂虛擬模型、桌面端 Agent 監控與請求網路階段耗時拆解。升級後未手動選過主題的使用者會切換為「簡潔」主題（既有選擇保持不變），Agent 監控預設未接入。

## 新功能
- **「簡潔」主題設為預設**：新增扁平分層外觀的「簡潔」主題，新安裝或未手動選過主題的使用者預設啟用；既有主題選擇保持不變，仍可在「設定」或側欄切換回「手繪」「經典」「Win2000」。
- **自訂虛擬模型**：除內建模型外，支援在「虛擬模型」中新建以 `model-` 開頭的自訂虛擬模型，為同一條或不同訂閱設定多條線路與上游模型對應。
  - 支援隨設定備份匯出與匯入；匯入時遇到同名自訂虛擬模型，會保留本機既有設定並給出提示。
- **即時路由頁改版**：改為基於真實流量的即時流向圖（用戶端 → 虛擬模型 → 訂閱），支援切換 5 / 15 / 60 分鐘時間窗、暫停畫面，並新增核心指標、請求用途分類、Token 消耗與訂閱負載檢視。
  - 即時清單支援從資料庫回填，重新啟動程式後不再空白；原頁面中的接入參考資訊已移至「接入指南」。
- **請求紀錄改版與獨立詳情頁**：清單改用按日分組並與即時路由共用顯示樣式，同一請求的重試嘗試歸併顯示；新增時間範圍、用途、工作階段篩選與關鍵字搜尋，篩選狀態隨網址保留，CSV 匯出同步補充用途、工作階段與追蹤 ID。
  - 請求詳情由彈窗改為獨立全頁，支援在目前篩選結果內切換上一筆和下一筆，集中呈現路由重試鏈、耗時、Token、同工作階段相鄰請求與三組請求頭。
- **請求網路階段耗時拆解**：每次上游嘗試記錄本機準備、DNS、連線（TCP 與 TLS）、等待首回應頭、連線複用、代理與上游位址，並在請求詳情中合併呈現網路與模型各階段耗時條。清單對超過 500 ms 的網路耗時額外標註，終端機介面（TUI）請求詳情同步增加網路分段；舊紀錄保留原有兩段耗時條。
- **訂閱管理與資料統計改版**：「訂閱管理」與「資料統計」頁面重新設計，資訊層次更緊湊直覺。
  - 「訂閱管理」頂部新增彙總列與「需要處理」提醒，每條訂閱一行呈現冷卻狀態、所屬虛擬模型、24 小時活躍條、最緊額度與行內開關，可就地展開檢視槽位模型和連線資訊；新增「複製訂閱」一鍵建立帶連線設定與 API Key 的副本（不帶路由綁定）。
  - 「資料統計」統一按頁級時間範圍檢視，新增 6 項核心指標環比、可切換請求數/Token/耗時圖表，以及按虛擬模型/訂閱/用戶端、請求用途、訂閱表現、常用工具與耗時分布的多維分析，各項均可直達對應篩選的請求紀錄。
- **Agent 監控與客戶端工作階段**（桌面端，預設未接入）：側欄新增「Agent 監控」頁，可為 Claude Code 與 Codex CLI 一鍵接入、停用或清理本機工作階段監控外掛；接入後需重新開啟對應客戶端，Codex 首次使用需在 `/hooks` 中信任外掛。
  - 啟用後可在「即時路由」底部的「客戶端工作階段」檢視即時工作階段狀態、上下文視窗、子代理、提示快取命中率、客戶端額度與累計用量。
- **ChatGPT Codex 瀏覽器登入與快取最佳化**：新增「瀏覽器登入 (推薦)」（透過本機 `localhost:1455` 回呼完成 OAuth PKCE 授權），同時保留「裝置碼登入」作為備選；OpenAI Responses 與 Codex 出站請求穩定透傳 `prompt_cache_key`（Codex 同步傳送 `session_id` 請求頭）以提升提示快取命中，推薦的 Codex `config.toml` 範本明確關閉 `supports_websockets = false`。
- **用戶端辨識擴充**：擴充請求用戶端指紋辨識，新增 OpenAI Python/JS SDK、curl、瀏覽器及常見 HTTP 用戶端與指令碼語言（Go、Rust、Python、Java、Node.js、Bun、Deno、PowerShell、PHP、Ruby 等）的自動辨識，體現在即時路由、請求紀錄與資料統計中。

## 修正
- **ChatGPT 權杖輪換穩定性**：修正 ChatGPT OAuth 更新權杖輪換時可能遺失原有帳號 ID 與電子郵件，或並行更新時重複使用舊更新權杖的問題。
