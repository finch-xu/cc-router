这是一个大版本：新增并默认启用「简洁」主题，全面改版实时路由、请求日志、订阅管理与数据统计四大核心页面；新增自定义虚拟模型、桌面端 Agent 监控与请求网络阶段耗时拆解。升级后未手动选过主题的用户会切换为「简洁」主题（已有选择保持不变），Agent 监控默认未接入。

## 新功能
- **「简洁」主题设为默认**：新增扁平分层外观的「简洁」主题，新安装或未手动选过主题的用户默认启用；已有主题选择保持不变，仍可在「设置」或侧栏切换回「手绘」「经典」「Win2000」。
- **自定义虚拟模型**：除内置模型外，支持在「虚拟模型」中新建以 `model-` 开头的自定义虚拟模型，为同一条或不同订阅配置多条线路与上游模型映射。
  - 支持随配置备份导出与导入；导入时遇到同名自定义虚拟模型，会保留本机已有配置并给出提示。
- **实时路由页改版**：改为基于真实流量的实时流向图（客户端 → 虚拟模型 → 订阅），支持切换 5 / 15 / 60 分钟时间窗、暂停画面，并新增核心指标、请求用途分类、Token 消耗与订阅负载视图。
  - 实时列表支持从数据库回填，重启应用后不再空白；原页面中的接入参考信息已移至「接入指南」。
- **请求日志改版与独立详情页**：列表改用按日分组并与实时路由共用展示样式，同一请求的重试尝试归并显示；新增时间范围、用途、会话筛选与关键词搜索，筛选状态随地址保留，CSV 导出同步补充用途、会话与追踪 ID。
  - 请求详情由弹窗改为独立全页，支持在当前筛选结果内切换上一条和下一条，集中展示路由重试链、耗时、Token、同会话相邻请求与三组请求头。
- **请求网络阶段耗时拆解**：每次上游尝试记录本地准备、DNS、连接（TCP 与 TLS）、等待首响应头、连接复用、代理与上游地址，并在请求详情中合并展示网络与模型各阶段耗时条。列表对超过 500 ms 的网络耗时额外标注，终端界面（TUI）请求详情同步增加网络分段；旧日志保留原有两段耗时条。
- **订阅管理与数据统计改版**：「订阅管理」与「数据统计」页面重新设计，信息层次更紧凑直观。
  - 「订阅管理」顶部新增汇总栏与「需要处理」提醒，每条订阅一行展示冷却状态、所属虚拟模型、24 小时活跃条、最紧配额与行内开关，可就地展开查看槽位模型和连接信息；新增「复制订阅」一键创建带连接配置与 API Key 的副本（不带路由绑定）。
  - 「数据统计」统一按页级时间范围查看，新增 6 项核心指标环比、可切换请求数/Token/耗时图表，以及按虚拟模型/订阅/客户端、请求用途、订阅表现、常用工具与耗时分布的多维分析，各项均可直达对应筛选的请求日志。
- **Agent 监控与客户端会话**（桌面端，默认未接入）：侧栏新增「Agent 监控」页，可为 Claude Code 与 Codex CLI 一键接入、停用或清理本机会话监控插件；接入后需重新打开对应客户端，Codex 首次使用需在 `/hooks` 中信任插件。
  - 启用后可在「实时路由」底部的「客户端会话」查看实时会话状态、上下文窗口、子代理、提示缓存命中率、客户端限额与累计用量。
- **ChatGPT Codex 浏览器登录与缓存优化**：新增「浏览器登录 (推荐)」（通过本机 `localhost:1455` 回调完成 OAuth PKCE 授权），同时保留「设备码登录」作为备选；OpenAI Responses 与 Codex 出站请求稳定透传 `prompt_cache_key`（Codex 同步发送 `session_id` 请求头）以提升提示缓存命中，推荐的 Codex `config.toml` 模板显式关闭 `supports_websockets = false`。
- **客户端识别扩展**：扩展请求客户端指纹识别，新增 OpenAI Python/JS SDK、curl、浏览器及常见 HTTP 客户端与脚本语言（Go、Rust、Python、Java、Node.js、Bun、Deno、PowerShell、PHP、Ruby 等）的自动识别，体现在实时路由、请求日志与数据统计中。

## 修复
- **ChatGPT 令牌轮换稳定性**：修复 ChatGPT OAuth 刷新令牌轮换时可能丢失原有账号 ID 与邮箱，或并发刷新时复用旧刷新令牌的问题。

## 其他
- **依赖更新**：更新 SQLite、Tauri 及前后端基础依赖版本。
