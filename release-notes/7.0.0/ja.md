メジャーアップデートです。「シンプル」テーマを新規追加して既定テーマとし、リアルタイムルーティング、リクエストログ、サブスクリプション、統計の 4 つの主要画面を刷新しました。また、カスタム仮想モデル、デスクトップ版エージェント監視、リクエストのネットワーク区間計測を追加しています。テーマを手動変更していない場合はアップデート後に「シンプル」へ切り替わります（保存済みの選択は維持されます）。エージェント監視は既定では未接続です。

## 新機能
- **「シンプル」テーマを既定に設定**：フラットで階層感のある「シンプル」テーマを追加し、新規インストールやテーマ未設定のユーザーに既定で適用します。既存の設定は維持され、「設定」またはサイドバーから「手描き」「クラシック」「Win2000」へいつでも戻せます。
- **カスタム仮想モデル**：組み込みモデルに加えて、「仮想モデル」から `model-` で始まるカスタム仮想モデルを作成し、同一または複数のサブスクリプションに対して複数のルートと上流モデルマッピングを設定できます。
  - 設定バックアップのエクスポートおよびインポートに対応しています。インポート時に同名のカスタム仮想モデルがある場合はローカル設定を保持し、通知を表示します。
- **リアルタイムルーティング画面の刷新**：実際のトラフィックに基づくフロー図（クライアント → 仮想モデル → サブスクリプション）へ刷新し、5 / 15 / 60 分の時間窓切替、一時停止、主要指標、リクエスト用途分類、トークン消費、サブスクリプション負荷ビューを追加しました。
  - データベースからの補完に対応し、再起動後も一覧が空にならなくなりました。従来の接続リファレンス情報は「セットアップガイド」へ移動しました。
- **リクエストログの刷新と独立した詳細ページ**：一覧を日付ごとのグループ表示かつリアルタイムルーティングと共通の行レイアウトへ変更し、同一リクエストのリトライ試行をまとめて表示します。期間・用途・セッションによる絞り込みとキーワード検索を追加し、絞り込み状態を URL に保持します。CSV エクスポートにも用途・セッション・トレース ID 列を追加しました。
  - リクエスト詳細をダイアログから独立した全画面ページへ変更し、現在の絞り込み内で前後のリクエストへ移動できるようにしました。リトライ経路、所要時間、トークン、同一セッションの前後リクエスト、3 種類のヘッダー表をまとめて確認できます。
- **ネットワーク区間の所要時間計測**：上流への試行ごとにローカル準備、DNS、接続（TCP・TLS）、先頭レスポンスヘッダー待機、接続再利用、プロキシ利用、上流アドレスを記録し、詳細ページでネットワークとモデルの各区間を 1 本のバーに統合表示します。一覧では 500 ms を超えるネットワーク時間を強調表示し、ターミナル UI（TUI）の詳細画面にもネットワーク区間を追加しました。旧ログは従来の 2 区間バーを維持します。
- **サブスクリプションと統計画面の刷新**：「サブスクリプション」と「統計」を再設計し、情報構造をより見やすく整理しました。
  - 「サブスクリプション」では上部にサマリーバーと「対応が必要」バナーを追加し、1 行ごとにクールダウン状態、紐づく仮想モデル、24 時間アクティビティバー、最も厳しい上限とインラインの有効切替を表示します。その場で展開してスロットモデルや接続情報を確認でき、接続設定と API Key を引き継ぐ「サブスクリプションを複製」（ルーティング紐づけは含まない）も追加しました。
  - 「統計」ではページ共通の期間指定へ統一し、前期比付きの主要 6 指標、リクエスト数・トークン・レイテンシ切替グラフに加え、仮想モデル・サブスクリプション・クライアント別、用途別、サブスクリプション別パフォーマンス、主要ツール、レイテンシ分布の分析を追加しました。各項目から同じ条件で絞り込んだリクエストログへ移動できます。
- **エージェント監視とクライアントセッション**（デスクトップ版のみ、既定では未接続）：サイドバーに「エージェント監視」画面を追加し、Claude Code と Codex CLI 向けのローカルセッション監視プラグインを接続・停止・解除できます。接続後は対象クライアントの再起動が必要で、Codex の初回利用時は `/hooks` でプラグインを信頼してください。
  - 有効にすると「リアルタイムルーティング」下部の「クライアントセッション」で、セッション状態、コンテキスト使用量、サブエージェント、プロンプトキャッシュ命中率、クライアント上限、累計使用量を確認できます。
- **ChatGPT Codex のブラウザログインとキャッシュ改善**：「ブラウザでログイン（推奨）」（ローカルの `localhost:1455` コールバックを使う OAuth PKCE 認証）を追加し、「デバイスコード」も引き続き選択できます。OpenAI Responses と Codex への送信リクエストで `prompt_cache_key` を安定して転送し（Codex には `session_id` ヘッダーも送信）、キャッシュ命中率を改善しました。推奨の Codex `config.toml` テンプレートでは `supports_websockets = false` を明示しています。
- **クライアント識別の拡張**：クライアントのフィンガープリント識別を拡張し、OpenAI Python/JS SDK、curl、ブラウザ、各種 HTTP クライアントおよびスクリプト言語（Go、Rust、Python、Java、Node.js、Bun、Deno、PowerShell、PHP、Ruby など）を自動識別して、リアルタイムルーティング・リクエストログ・統計へ反映します。

## 修正
- **ChatGPT トークン更新の安定性**：ChatGPT OAuth のリフレッシュトークン更新時にアカウント ID やメールアドレスが失われたり、同時更新時に古いリフレッシュトークンが再利用されたりする不具合を修正しました。

## その他
- **依存関係の更新**：SQLite、Tauri およびフロントエンド・バックエンドの基盤依存パッケージを更新しました。
