这一版新增 Jev / System One 决策模型入口，并接入 Cloudflare Workers AI 与 Cloudflare Clef；实时路由页可以看到哪些客户端真正接入了 cc-router。升级后对话类请求的行为不变；导出小票时默认播放出票动画，可以关闭。

## 新功能
- **Jev / System One 决策模型**：新增入口 `POST /v1/systemone` 与虚拟模型 `model-jev`。决策模型输入一段状态和一组问题，返回每个问题的结构化答案；接入后同样享有多订阅调度、冷却、限额与请求日志。请求原样转发，不做协议转换。
  - 内置上游：TypeSafe（Jev）、Cloudflare Clef，以及 OpenRouter 与 Ollama 的 System One 接入点（Ollama 需要 0.35 或更高版本）。
  - `model-jev` 只能绑定 System One 订阅，对话类订阅不能绑进来；三个对话入口收到 `model-jev` 会直接拒绝。
  - 添加 System One 订阅时只配置一个可选的 Jev 模型槽。请求里写 `model-jev` 时改写成这个槽的模型，槽为空时用接入点的示例模型。
  - 虚拟模型页新增 model-jev 卡片，可以复制已填好地址与令牌的 curl 示例；接入指南 → 通用接入方式新增 Jev 接入卡片。
  - 用量小票计入 model-jev 的用量（有用量时才出现）；终端界面同样支持 model-jev 与 System One 订阅。
- **Cloudflare Workers AI 与 Cloudflare Clef**：新增两个内置厂商。Workers AI 提供 gpt-oss、Kimi、GLM 等对话模型，经 OpenAI Chat Completions 协议转换；Clef 是 Cloudflare 的决策模型，只用于 model-jev。
  - 两个厂商都可以选择直连或经 AI Gateway 接入。添加订阅时填写账户 ID，经 AI Gateway 时还要填网关 ID；编辑订阅时也可以修改。
  - API Token 需要 Workers AI 权限，经 AI Gateway 时还需要 AI Gateway 权限。
  - Workers 免费计划只能使用部分模型（gpt-oss 可用，Kimi / GLM 需要付费计划）。不可用的模型会返回 403，订阅会被标记为鉴权失败。
- **厂商列表显示能力标签**：添加订阅时，厂商下拉的每一项后面标出 LLM（可接对话）或 Jev（可接决策模型），两种都支持的厂商同时显示两个。终端界面的新建向导同样显示。
- **模型下拉支持模糊搜索，可直接使用列表外的模型**：搜索时忽略大小写与 `-` `_` `.` `/` 等分隔符，例如输入 `glm5` 能找到 `@cf/zai-org/glm-5.3`。
  - 输入的名字不在模型列表里时，下拉中会多出一项「使用 …」，选中即填入槽位，不用再切到手动模式。
  - 模型很多时一次最多显示 200 个，继续输入可以缩小范围。
  - 已选但不在列表里的模型现在标为「(列表外)」。
- **实时路由新增「客户端接入」**（#55，感谢 @Wade11s）：按真实请求检测哪些客户端已经接入 cc-router，路由图里没有发过请求的客户端便签会变灰。
  - 下方表格按客户端系列分组，显示最近请求时间、请求数与 Token 数。
  - 检测范围等于请求日志的保留期，日志已被清理的客户端会显示为未接入。
- **导出小票时播放出票动画**（默认开启）：点导出后小票机把小票打印出来，约 2 秒，可以随时跳过，导出本身不受影响。在用量小票页的「导出小票」卡片里可以关闭；系统开启了减少动态效果时直接显示完成状态。
- **侧栏新增「备份与迁移」入口**：直接打开设置里的备份与迁移标签。

## 修复
- **请求日志右侧几列被裁掉**：默认窗口宽度从 1200 提高到 1360。
- **Linux AppImage 在 Ubuntu 26 上白屏**：同时修复了 AppImage 以其他用户身份或在 firejail 下启动时因权限不足而失败的问题。

## 其他
- 导入配置时，内置厂商的订阅按当前版本的厂商配置重新生成连接地址与附加请求头，不再沿用备份文件里的值；API Key、模型槽位等其他设置照常从备份导入。
- 接入指南的 Codex 标签现在可用：改为三步手动修改 `config.toml` 与 `auth.json` 的文字教程，配置片段按你的端口与访问令牌生成，替代此前一直不可用的一键写入编辑器。
- 接入指南 → 通用接入方式的页面顶部新增本页目录。
- 前端依赖 dompurify 升级到 3.4.16，修复其安全公告。
