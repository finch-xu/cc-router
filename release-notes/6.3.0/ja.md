このバージョンでは、Jev / System One 意思決定モデルの入口を追加し、Cloudflare Workers AI と Cloudflare Clef に対応しました。リアルタイムルーティングのページでは、実際に cc-router に接続しているクライアントを確認できます。アップグレード後も会話リクエストの動作は変わりません。レシートのエクスポート時にはデフォルトで印刷アニメーションが再生されますが、オフにできます。

## 新機能
- **Jev / System One 意思決定モデル**：入口 `POST /v1/systemone` と仮想モデル `model-jev` を追加しました。意思決定モデルは状態と質問のセットを受け取り、質問ごとに構造化された回答を返します。cc-router 経由でも、複数サブスクリプションのスケジューリング、クールダウン、使用量上限、リクエストログがそのまま使えます。リクエストはプロトコル変換せずにそのまま転送します。
  - 組み込みの上流：TypeSafe（Jev）、Cloudflare Clef、OpenRouter と Ollama の System One エンドポイント（Ollama は 0.35 以降が必要）。
  - `model-jev` には System One のサブスクリプションしか割り当てられず、会話用のサブスクリプションは割り当てられません。3 つの会話用入口は `model-jev` を受け取ると拒否します。
  - System One のサブスクリプションは、任意の Jev モデルスロットを 1 つだけ設定します。リクエストで `model-jev` を指定するとこのスロットのモデルに書き換えられ、スロットが空ならエンドポイントのサンプルモデルを使います。
  - 仮想モデルのページに model-jev カードを追加し、アドレスとトークンを埋め込んだ curl の例をコピーできます。セットアップガイド → 汎用接続方法に Jev の接続カードを追加しました。
  - 利用レシートに model-jev の使用量を含めます（使用量があるときのみ表示）。ターミナル UI でも model-jev と System One のサブスクリプションを扱えます。
- **Cloudflare Workers AI と Cloudflare Clef**：組み込みプロバイダーを 2 つ追加しました。Workers AI は gpt-oss、Kimi、GLM などの会話モデルを提供し、OpenAI Chat Completions プロトコル経由で変換します。Clef は Cloudflare の意思決定モデルで、model-jev 専用です。
  - どちらも直接接続と AI Gateway 経由を選べます。サブスクリプションの追加時にアカウント ID を入力し、AI Gateway 経由の場合はゲートウェイ ID も入力します。サブスクリプションの編集時にも変更できます。
  - API トークンには Workers AI の権限が必要で、AI Gateway 経由の場合は AI Gateway の権限も必要です。
  - Workers 無料プランでは一部のモデルしか使えません（gpt-oss は利用可、Kimi / GLM は有料プランが必要）。利用できないモデルは 403 を返し、サブスクリプションは認証失敗として扱われます。
- **プロバイダー一覧に機能タグを表示**：サブスクリプションの追加時、プロバイダーのドロップダウンの各項目に LLM（会話）または Jev（意思決定モデル）のタグを表示します。両方に対応するプロバイダーには両方のタグが付きます。ターミナル UI の新規作成ウィザードでも同様に表示します。
- **モデルのドロップダウンであいまい検索と一覧外のモデル指定に対応**：検索時に大文字・小文字や `-` `_` `.` `/` などの区切り文字を無視します。たとえば `glm5` と入力すると `@cf/zai-org/glm-5.3` が見つかります。
  - 入力した名前がモデル一覧にない場合、ドロップダウンに「…を使用」が表示され、選ぶとそのままスロットに入ります。手動モードに切り替える必要はありません。
  - モデルが多い場合は一度に最大 200 件まで表示します。続けて入力すると絞り込めます。
  - 選択済みで一覧にないモデルは「（一覧外）」と表示するようになりました。
- **リアルタイムルーティングに「クライアント接続」を追加**（#55、@Wade11s さんに感謝）：実際のリクエストから、cc-router に接続しているクライアントを検知します。ルーティング図では、一度もリクエストを送っていないクライアントの付箋がグレー表示になります。
  - 下の表はクライアントの系列ごとにグループ化され、最終リクエストの時刻、リクエスト数、トークン数を表示します。
  - 検知範囲はリクエストログの保持期間と同じです。ログが削除済みのクライアントは未接続と表示されます。
- **レシートのエクスポート時に印刷アニメーションを再生**（デフォルトでオン）：エクスポートをクリックすると、レシートプリンターが約 2 秒でレシートを印刷します。いつでもスキップでき、エクスポート自体には影響しません。利用レシートのページの「レシートをエクスポート」カードでオフにできます。システムで視差効果を減らす設定がオンの場合は、完了した状態をすぐに表示します。
- **サイドバーに「バックアップ」を追加**：設定のバックアップと移行タブを直接開きます。

## 修正
- **リクエストログの右側の列が切れる**：デフォルトのウィンドウ幅を 1200 から 1360 に広げました。
- **Linux の AppImage が Ubuntu 26 で白い画面になる**：あわせて、AppImage を別のユーザーとして、または firejail 上で起動したときに権限エラーで起動できない問題も修正しました。

## その他
- 設定のインポート時、組み込みプロバイダーのサブスクリプションは、バックアップファイルの値を使わず、このバージョンのプロバイダー定義から接続先と追加リクエストヘッダーを作り直します。API Key やモデルスロットなどの設定は、これまでどおりバックアップからインポートされます。
- セットアップガイドの Codex タブが使えるようになりました。`config.toml` と `auth.json` を手動で編集する 3 ステップの説明で、設定の断片はお使いのポートとアクセストークンから生成されます。これまで使えなかったワンクリック書き込みエディターは削除しました。
- セットアップガイド → 汎用接続方法のページ上部に「このページの目次」を追加しました。
- フロントエンドの依存パッケージ dompurify を 3.4.16 に更新し、セキュリティアドバイザリに対応しました。
