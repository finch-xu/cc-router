このバージョンでは、OpenAI 形式のモデルエイリアスを astra / sol / terra / luna の 4 ティアに変更し、fable / opus / sonnet / haiku と一対一で対応させました。また、設定画面の Web UI カードにログイントークンが表示されるようになりました。エイリアスの変更は互換性のない変更です：`gpt-*-sol`、`gpt-*-terra`、`gpt-*-luna` はそれぞれ 1 ティア下がり、`gpt-5.5` のようなバージョン番号のみの名前と `gpt-*-mini` は認識されなくなります。Codex などのクライアントでこれらの名前を使っている場合は、アップグレード後に下の対応表に従って一度書き換えてください。`model-*` や `claude-*` の名前を使っている場合は影響ありません。

## 新機能
- **OpenAI 形式のモデルエイリアスを 4 ティアに変更**（互換性のない変更）：クライアントが指定できる `gpt-*` エイリアスは astra / sol / terra / luna になりました。名前に含まれるティア名で一致し、バージョン番号は問いません。`gpt-6-sol`、`gpt-6.1-sol`、`openai/gpt-6-sol` はいずれも sol ティアです。
  - `gpt-*-astra` は `model-fable` に対応します（新規）。
  - `gpt-*-sol` は `model-opus` に対応します（以前は `model-fable`）。
  - `gpt-*-terra` は `model-sonnet` に対応します（以前は `model-opus`）。
  - `gpt-*-luna` は `model-haiku` に対応します（以前は `model-sonnet`）。
  - `gpt-5.6`、`gpt-5.5`、`gpt-5.4` と `gpt-*-mini` は認識されなくなり、これらの名前のリクエストは `model-fallback` に回ります。上のティア名を使うか、`model-opus` のような仮想モデル名を直接指定してください。
- **Web UI カードにログイントークンを表示**：設定 → Web & TUI → Web UI で「ログイン認証」が有効なとき、アクセス URL の下に「ログイントークン」の行が表示され、そのままコピーできます。
  - これまでトークンは「セキュリティとアクセス」タブで「トークン認証」が有効なときにしか表示されず、無効だと確認できませんでした。Web のログイン画面の案内も新しい場所を指すようになりました。

## その他
- **アップデートページの新バージョンの内容**：見出し、リスト、太字、リンクが整形して表示され、現在の表示言語の部分だけが表示されます。3 言語の全文をプレーンテキストでまとめて表示することはなくなりました。
- **`GET /v1/models` のモデル一覧を更新**：Claude のエイリアスは各ティア 5.5 と 6 の 2 バージョン（例：`claude-opus-5-5`、`claude-opus-6`）、OpenAI のエイリアスは各ティア 1 つ（例：`gpt-6-sol`）になり、合計 32 件です。`claude-opus-4-7` のような以前の書き方も引き続きルーティングされますが、一覧には表示されなくなりました。
- セットアップガイド → 汎用接続方法のモデル表と、リアルタイムルーティングページのエイリアス案内を新しいルールに合わせて更新しました。
