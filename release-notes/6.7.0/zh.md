本次更新完善请求日志与请求头控制，新增速度和首字时间，并改善上游兼容性。升级后默认开启请求头记录，可在「设置 → 高级 → 记录请求头」关闭。

## 新功能
- **请求头透传与预览**：Anthropic 透传订阅支持不透传、Claude Code 预设、白名单、黑名单和透传全部五种模式；内置订阅也可添加自定义请求头。「预览发送效果」使用示例请求展示当前未保存设置的发送结果和来源，不会请求上游。
  - 新建 Anthropic 官方订阅默认使用 Claude Code 预设，第三方订阅默认不透传；已有设置自动迁移。敏感请求头仍受保护，备份会省略敏感自定义头值，导入时提示重新填写。
  - 增加 Claude Code auto mode 兼容性提示，并可复制 `CLAUDE_CODE_AUTO_MODE_SERVER=0` 环境变量配置。
- **请求日志详情**：按分类切换概览、客户端请求头、上游请求头和上游响应头；概览统一用表格展示，请求头可查看来源及是否返回客户端，敏感值脱敏显示。旧日志不补录请求头。
- **速度与首字时间**：请求日志列表、详情、复制内容和 CSV 导出新增这两项指标。首字时间以首次实际文本、思考或工具调用内容为准；速度为扣除首字等待后的平均输出 token 速率。非流式或数据不足时显示「—」；失败请求不显示速度，已测得的首字时间仍保留。
- **Token 计数入口**：支持 `/v1/messages/count_tokens`，通过 Anthropic 透传订阅计数；没有可用计数入口时返回不支持，让客户端回退估算。计数请求不计入请求日志或配额；同时支持 `HEAD /api/hello` 连接预热探测。
- **上游响应自动解压**：自动协商并解压 gzip、deflate、Brotli 和 zstd 响应，流式响应持续增量转发，无需额外设置。

## 修复
- **上游错误与重试信息**：保留适用的上游错误状态、正文及重试、限流响应头；修复协议翻译入口遇到非 JSON 错误时变成 500 的问题，上游鉴权失败也不再被误报为客户端凭据失效。
- **请求耗时统计**：流式请求耗时包含等待上游响应头的时间，并按每次尝试独立计时，避免把前一次重试的耗时算入当前记录。
- **请求头字符兼容性**：透传时保留含非 ASCII 字符的 UTF-8 请求头值，避免被静默丢弃。

## 其他
- **CA 证书导出**：桌面端和网页界面统一导出带时间戳的 ZIP，内含 PEM 和 CRT 两种证书文件。
- **默认请求体上限**：新安装或未保存此项设置时默认使用 128 MB，已有保存值保持不变。
- **依赖更新**：更新网络与桌面组件，包含 TLS 和 Windows 自动更新相关安全修复。
