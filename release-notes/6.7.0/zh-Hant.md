本次更新完善請求紀錄與請求頭控制，新增速度和首字時間，並改善上游相容性。升級後預設開啟請求頭記錄，可在「設定 → 進階 → 記錄請求頭」關閉。

## 新功能
- **請求頭透傳與預覽**：Anthropic 透傳訂閱支援不透傳、Claude Code 預設集、白名單、黑名單和全部透傳五種模式；內建訂閱也可新增自訂請求頭。「預覽送出效果」使用範例請求展示目前尚未儲存設定的送出結果和來源，不會向上游發出請求。
  - 新建 Anthropic 官方訂閱預設使用 Claude Code 預設集，第三方訂閱預設不透傳；既有設定自動遷移。敏感請求頭仍受保護，備份會省略敏感自訂頭值，匯入時提示重新填寫。
  - 新增 Claude Code auto mode 相容性提示，並可複製 `CLAUDE_CODE_AUTO_MODE_SERVER=0` 環境變數設定。
- **請求紀錄詳情**：依分類切換概覽、用戶端請求頭、上游請求頭和上游回應頭；概覽統一以表格呈現，請求頭可查看來源及是否回傳用戶端，敏感值遮蔽顯示。舊紀錄不補記請求頭。
- **速度與首字時間**：請求紀錄清單、詳情、複製內容和 CSV 匯出新增這兩項指標。首字時間以首次實際文字、思考或工具呼叫內容為準；速度為扣除首字等待後的平均輸出 token 速率。非串流或資料不足時顯示「—」；失敗請求不顯示速度，已測得的首字時間仍保留。
- **Token 計數入口**：支援 `/v1/messages/count_tokens`，透過 Anthropic 透傳訂閱計數；沒有可用計數入口時回傳不支援，讓用戶端退回估算。計數請求不計入請求紀錄或配額；同時支援 `HEAD /api/hello` 連線預熱探測。
- **上游回應自動解壓縮**：自動協商並解壓縮 gzip、deflate、Brotli 和 zstd 回應，串流回應持續增量轉發，無須額外設定。

## 修正
- **上游錯誤與重試資訊**：保留適用的上游錯誤狀態、本文及重試、速率限制回應頭；修正協定轉換入口遇到非 JSON 錯誤時變成 500 的問題，上游驗證失敗也不再被誤報為用戶端憑證失效。
- **請求耗時統計**：串流請求耗時包含等待上游回應頭的時間，並依每次嘗試獨立計時，避免把前一次重試的耗時算入目前紀錄。
- **請求頭字元相容性**：透傳時保留含非 ASCII 字元的 UTF-8 請求頭值，避免被無聲捨棄。

## 其他
- **CA 憑證匯出**：桌面端和網頁介面統一匯出帶時間戳記的 ZIP，內含 PEM 和 CRT 兩種憑證檔案。
- **預設請求本文上限**：新安裝或尚未儲存此項設定時預設使用 128 MB，既有儲存值保持不變。
- **相依套件更新**：更新網路與桌面元件，包含 TLS 和 Windows 自動更新相關安全修正。
