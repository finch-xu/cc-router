リクエストログとヘッダー制御を改善し、速度と初回出力時間を追加しました。上流との互換性も改善しています。アップグレード後はヘッダー記録が既定で有効になります。「設定 → 詳細 → リクエストヘッダーを記録」で無効にできます。

## 新機能
- **ヘッダー転送とプレビュー**：Anthropic パススルーのサブスクリプションで「転送しない」「Claude Code プリセット」「許可リスト」「拒否リスト」「すべて転送」の 5 モードを選べます。組み込みサブスクリプションにもカスタムヘッダーを追加できます。「送信内容をプレビュー」ではサンプルリクエストを使い、未保存の設定による送信結果と由来を表示します。上流へのリクエストは行いません。
  - 新規の Anthropic 公式サブスクリプションは Claude Code プリセット、サードパーティは「転送しない」が既定です。既存の設定は自動移行します。機密ヘッダーの保護は維持され、バックアップでは機密性のあるカスタムヘッダーの値を省略し、インポート時に再入力を案内します。
  - Claude Code auto mode の互換性に関する案内を追加し、環境変数 `CLAUDE_CODE_AUTO_MODE_SERVER=0` の設定をコピーできるようにしました。
- **リクエストログの詳細**：概要、クライアントのリクエストヘッダー、上流へのリクエストヘッダー、上流のレスポンスヘッダーを分類ごとに切り替えられます。概要を表形式に統一し、ヘッダーの由来とクライアントへの返却有無を表示します。機密値はマスクされます。過去のログにヘッダーは補完されません。
- **速度と初回出力時間**：リクエストログの一覧、詳細、コピー内容、CSV エクスポートに追加しました。初回出力時間は実際のテキスト、思考、ツール呼び出し内容が最初に届くまでの時間です。速度は初回待機を除いた平均出力 token レートです。非ストリーミングやデータ不足の場合は「—」を表示します。失敗したリクエストの速度は表示せず、測定済みの初回出力時間は保持します。
- **Token 計数エンドポイント**：Anthropic パススルーのサブスクリプション経由で `/v1/messages/count_tokens` に対応します。利用できる計数エンドポイントがない場合は非対応を返し、クライアントが推定に切り替えられるようにします。計数リクエストはリクエストログやクォータに計上されません。`HEAD /api/hello` による接続ウォームアップにも対応します。
- **上流レスポンスの自動展開**：gzip、deflate、Brotli、zstd を自動交渉して展開します。ストリーミングレスポンスは引き続き逐次転送され、追加設定は不要です。

## 修正
- **上流エラーと再試行情報**：適用可能な上流エラーのステータス、本文、再試行・レート制限ヘッダーを保持します。プロトコル変換の入口で JSON 以外のエラーが 500 になる問題を修正し、上流の認証失敗をクライアントの認証情報の失効として誤報しなくなりました。
- **リクエスト所要時間**：ストリーミングの所要時間に上流レスポンスヘッダーの待機を含めます。試行ごとに独立して計測し、前の試行にかかった時間が現在の記録に混ざることを防ぎます。
- **ヘッダー文字の互換性**：非 ASCII 文字を含む UTF-8 ヘッダー値が、パススルーで無言のまま破棄されず保持されます。

## その他
- **CA 証明書のエクスポート**：デスクトップと Web UI で、PEM と CRT の両形式を含むタイムスタンプ付き ZIP をエクスポートします。
- **リクエスト本文の既定上限**：新規インストールまたは保存値がない場合は 128 MB になります。既存の保存値は変更しません。
- **依存関係の更新**：ネットワークとデスクトップのコンポーネントを更新しました。TLS と Windows の自動更新に関するセキュリティ修正を含みます。
