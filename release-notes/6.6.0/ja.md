今回の更新では、段階的な初期設定ガイドとデスクトップ画面のズーム設定を追加しました。初回設定が進めやすくなり、画面をよりコンパクトに使えます。Cheaper Inference プロバイダーも追加しました。

## 新機能
- **初期設定ガイド**：言語と外観、免責事項の確認から、サブスクリプションの追加、モデル選択、接続テスト、AI ツールの接続まで順に進み、最後に設定内容を確認できます。
  - 通常の追加画面やバックアップのインポートからも続行できます。免責事項への同意後は設定を後回しにしてサイドバーから再開でき、設定画面からガイドを開き直すこともできます。
  - Claude Code の設定書き込み、Codex の設定コピー、その他のツールの接続ガイドへのリンクを用意しました。
- **デスクトップ画面のズーム**：「設定 → 一般 → 外観」で 80%、90%、100%、110%、125% から選択できます。変更は即時反映され、次回起動時も維持されます。初期値とリセット値は 90% です。
- **Cheaper Inference プロバイダー**（#65、@aiapienthusiast に感謝）：Anthropic Messages 互換エンドポイント、API キー認証、モデル一覧の取得を追加しました。互換性は引き続き未テストとして表示されます。

## 修正
- **狭いウィンドウでのレイアウト**：設定画面の初期設定ガイドのボタンが行全体に広がらないようにしました。リクエストログの表は最小幅を維持し、表内の横スクロールで右端の列を確認できます。長い名前や大きな数値によるレイアウトの崩れも防ぎます。

## その他
- **既定のデスクトップウィンドウをコンパクトに**：初期幅を 1280 に変更し、小さい画面への対応は維持しました。Windows での追加の自動拡大をなくし、選択した倍率を一貫して使用します。
- **README の機能紹介**：ターミナル UI の章の後に、時間帯別の仮想モデルの説明、時間帯設定とルーティングプレビューの画像を追加しました。中国語の README 2 種類には中国語画像、それ以外には英語画像を使用しています。
