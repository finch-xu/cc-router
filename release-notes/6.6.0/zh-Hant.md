本次更新加入分步新手引導和可調整的桌面介面縮放，讓首次設定更順暢、日常使用更緊湊，並新增 Cheaper Inference 供應商。

## 新功能
- **分步新手引導**：從語言與外觀、免責聲明開始，逐步完成新增訂閱、選擇模型、測試連線及串接 AI 工具，最後查看設定摘要。
  - 支援從完整新增頁面或備份匯入繼續；同意免責聲明後可以稍後設定，並從側邊欄繼續，也可在設定中重新開啟引導。
  - 提供 Claude Code 設定寫入、Codex 設定複製和其他工具串接指南入口。
- **桌面介面縮放**：在「設定 → 一般 → 外觀」選擇 80%、90%、100%、110% 或 125%，立即生效並記住選擇；預設及重設值為 90%。
- **Cheaper Inference 供應商**（#65，感謝 @aiapienthusiast）：新增 Anthropic Messages 相容端點、API Key 驗證及模型清單探索；相容性仍標記為未測試。

## 修正
- **緊湊視窗下的版面配置**：設定中「新手引導」右側按鈕不再撐滿整行；請求記錄表格保留最小寬度，透過表格內橫向捲動查看右側欄位，長名稱及大數值不會擠亂版面。

## 其他
- **更緊湊的預設桌面視窗**：初始寬度調整為 1280，保留小螢幕適配；移除 Windows 上額外的自動放大，讓介面統一使用所選縮放比例。
- **README 功能展示**：在終端介面章節後新增分時段虛擬模型的介紹、時段設定圖及路由預覽圖；兩份中文 README 使用中文截圖，其他語言使用英文截圖。
