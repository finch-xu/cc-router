本次更新加入分步新手引导和可调节的桌面界面缩放，让首次配置更顺畅、日常使用更紧凑，并新增 Cheaper Inference 提供商。

## 新功能
- **分步新手引导**：从语言与外观、免责声明开始，逐步完成添加订阅、选择模型、测试连接和接入 AI 工具，最后查看配置摘要。
  - 支持从完整添加页或备份导入继续；同意免责声明后可以稍后设置，并从侧栏继续，也可在设置中重新打开引导。
  - 提供 Claude Code 配置写入、Codex 配置复制和其他工具接入指南入口。
- **桌面界面缩放**：在「设置 → 通用 → 外观」选择 80%、90%、100%、110% 或 125%，立即生效并记住选择；默认及重置值为 90%。
- **Cheaper Inference 提供商**（#65，感谢 @aiapienthusiast）：新增 Anthropic Messages 兼容端点、API Key 鉴权和模型列表发现；兼容性仍标记为未测试。

## 修复
- **紧凑窗口下的布局**：设置中「新手引导」右侧按钮不再撑满整行；请求日志表格保留最小宽度，通过表格内横向滚动查看右侧列，长名称和大数值不会挤乱布局。

## 其他
- **更紧凑的默认桌面窗口**：初始宽度调整为 1280，保留小屏幕适配；移除 Windows 上额外的自动放大，使界面统一使用所选缩放比例。
- **README 功能展示**：在终端界面章节后新增分时段虚拟模型的介绍、时段设置图和路由预览图；两份中文 README 使用中文截图，其他语言使用英文截图。
