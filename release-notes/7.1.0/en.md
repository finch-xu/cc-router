This release introduces Sparrow Bakery, a data-only plugin hub supporting six plugin types: UI themes, receipt themes, providers, pricing, rules, and notifiers. It also adds built-in system desktop notifications, the built-in Sparrow theme, one-click subscription connection rebuilds, and unified receipt display settings. Default behavior stays largely unchanged on upgrade (except receipt footer codes now default to Barcode); system desktop notifications are off by default, and rules and notifier plugins start disabled after installation.

## Features
- **Sparrow Bakery plugin hub**: Adds a Plugins entry to the sidebar to browse, search, and filter the community catalog, as well as "Install from link" (GitHub repository URLs pinned to a specific commit) and "Load from folder"; every plugin links to its homepage and pinned source commit.
  - All plugins contain data only and never run code; installing, uninstalling, and enabling are desktop-only, while the web UI can view and use installed plugins; pricing and rules plugins can be reordered by priority in the Installed list.
- **UI theme and receipt theme plugins**: Install community or third-party "UI theme" plugins (with pre-install "Try on" preview for colors and shapes) and "Receipt theme" plugins (previewed with sample data before installation, with PNG, PDF, and HTML export); plugins from the community show a "Community" tag in Settings, the Receipts theme picker, and the Plugins page.
- **Provider plugins and subscription connection rebuild**: Install "Provider" plugins to add upstreams beyond the built-in list, with a pre-install summary of domains receiving your API key, capability diffs on updates, and declarative JSON balance queries; uninstalling a provider plugin leaves existing subscriptions running off their saved connection snapshot.
  - Subscription edit pages now display a "Provider description updated" banner (for both built-in and plugin providers) with a field-by-field diff and one-click "Rebuild connection".
- **Pricing plugins and cost tracking**: Install "Pricing" plugins to compute estimated costs on demand from the current price table for both historical summaries and individual requests with no backfill step; adds a Costs card on Statistics, per-request estimates in Request logs details, and cost fields for plugin receipts.
  - When a pricing plugin is enabled, subscription editing adds a "Billing" option (Pay as you go / Flat-rate plan); flat-rate subscriptions are reported separately as "Flat-rate equivalent" rather than added to metered spend, and USD and CNY totals are kept separate.
- **Rules plugins** (disabled by default): Apply data-only rules before routing (reroute to another virtual model or reject requests) and before sending (append to system prompt, set or clamp sampling/thinking parameters, remove tool definitions, or redact text); `/v1/systemone` is exempt.
  - Includes a dynamic parameter form and "Dry run" preview against recent request logs; updates that expand capabilities or change parameters automatically disable the plugin; Request logs details show matched rules plugins and rule IDs.
- **System desktop notifications and notifier plugins** (off / disabled by default): Adds built-in desktop alerts and remote push notifications for subscription incidents, proxy stops, and daily usage summaries.
  - **System desktop notifications** (off by default): Enable under Settings → General → Notifications, select events (defaulting to Subscription auth failed, Subscription quota reached, and Proxy stopped unexpectedly), and set "Daily summary time" (default 21:00); identical events are deduped for 10 minutes (consecutive "All candidate subscriptions failed" events coalesce into a count), with test notifications and click-to-navigate to the matching page.
  - **Notifier plugins** (disabled by default): Push selected events to mobile or team chat channels (such as ntfy, Bark, Feishu, DingTalk, Telegram, and Slack) without sending API keys, prompts, or headers; supports masked secret storage, "Save & send test", and "Recent deliveries".
- **Built-in Sparrow theme**: Adds the warm-cream, ginger-accent Sparrow theme built on Quiet (using water-blue for in-flight Live routing traffic), selectable from Settings → General → Appearance or the sidebar, and adds onboarding previews for both Quiet and Sparrow.
- **Unified receipt settings and barcode default**: "Footer code" and compact numbers now apply across all receipt themes, while grouping, "Show cache tokens", and request counts apply to both Classic and plugin receipts; "Footer code" now defaults to "Barcode" to avoid QR codes being blocked in shared images on some platforms.

## Fixes
- **Desktop confirmation dialogs skipping user confirmation**: Fixes an issue where desktop confirmation prompts (uninstalling plugins, regenerating HTTPS certificates, clearing Agent Monitoring connections, resetting cumulative subscription quotas, discarding unsaved config editor changes, and web auth / proxy restart confirmations) proceeded immediately without waiting for user confirmation.
