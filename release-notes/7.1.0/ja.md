このバージョンでは、UI テーマ・レシートテーマ・プロバイダー・料金・ルール・通知の 6 種類のデータ専用プラグインに対応するコミュニティ創作センター「Sparrow Bakery · スズメベーカリー」を追加しました。あわせて、システムデスクトップ通知、内蔵「スズメ」テーマ、サブスクリプション接続の再構築、利用レシート表示設定の統一を導入しています。アップデート後の既定動作はほぼ変わりません（利用レシートのフッターコードのみ既定がバーコードに変更）。システムデスクトップ通知は既定でオフ、ルール・通知プラグインはインストール直後は無効です。

## 新機能
- **プラグインセンター（Sparrow Bakery · スズメベーカリー）**：サイドバーにプラグイン画面を追加しました。コミュニティカタログの閲覧・検索・種別絞り込みに加え、「リンクからインストール」（GitHub リポジトリ URL を指定コミットに固定）と「フォルダから読み込む」に対応し、各プラグインの紹介ページと固定コミットのソースを確認できます。
  - すべてのプラグインはデータのみで構成され、コードは一切実行されません。インストール・アンインストール・有効化などの管理操作はデスクトップ版のみで、Web UI ではインストール済みプラグインの閲覧と利用のみ行えます。料金・ルールプラグインはインストール済み一覧で優先度を並び替えられます。
- **UI テーマ・レシートテーマプラグイン**：コミュニティやサードパーティ製の「UIテーマ」プラグイン（インストール前に色と形を確認できる「試着」に対応）と「レシートテーマ」プラグイン（サンプルデータでの事前プレビュー、PNG・PDF・HTML 書き出しに対応）をインストールできます。コミュニティ由来のプラグインには、設定・レシート選択・プラグイン画面で「コミュニティ」タグが表示されます。
- **プロバイダープラグインとサブスクリプション接続の再構築**：「プロバイダー」プラグインで内蔵以外の接続先を追加できます。インストール前に API キーの送信先ドメイン一覧と更新時の差分を表示し、宣言的な JSON 残高照会にも対応します。アンインストール後も既存のサブスクリプションは保存済みの接続情報で動作を継続します。
  - サブスクリプション編集画面に「プロバイダーの記述が更新されました」バナーを追加しました（内蔵・プラグイン双方に対応）。項目ごとの新旧差分を確認してワンクリックで「接続を再構築」できます。
- **料金プラグインと費用集計**：「料金」プラグインをインストールして有効にすると、現在の料金表から履歴および個別リクエストの概算費用をリアルタイム算出します（再集計は不要）。「統計」に費用カード、「リクエストログ」詳細に個別リクエストの概算費用を表示し、プラグインレシートからも費用フィールドを参照できます。
  - 料金プラグインが有効なとき、サブスクリプション編集画面に「課金方式」（従量課金 / 定額プラン）が表示されます。定額サブスクは「定額サブスクの相当額」として従量課金の費用とは分けて集計され、USD と CNY も別々に表示されます。
- **ルールプラグイン**（インストール直後は無効）：ルーティング前（別仮想モデルへの振り分け・リクエスト拒否）および送信前（system へのテキスト追記、サンプリング・思考パラメータの設定や制限、ツール定義の削除、伏せ字置換）にリクエストへルールを適用できます（`/v1/systemone` は対象外）。
  - 動的フォームでのパラメータ設定と、最近のリクエストログを使った「テスト実行」プレビューに対応しています。更新時に機能追加やパラメータ変更があると自動で無効化され、リクエスト詳細には適用されたルールプラグインとルール ID が表示されます。
- **システムデスクトップ通知と通知プラグイン**（既定でオフ / インストール直後は無効）：サブスクリプション異常・プロキシ停止・日次利用量を知らせるデスクトップ通知とプッシュ通知を追加しました。
  - **システムデスクトップ通知**（既定でオフ）：「設定 → 一般 → 通知」で有効化でき、通知イベントの選択（既定はサブスク認証エラー・サブスク上限到達・プロキシ異常停止）と「日次サマリー時刻」（既定 21:00）を設定できます。同一イベントは 10 分間重複抑制され（期間内の連続「すべての候補サブスクが失敗」は件数を合算）、テスト通知送信や通知クリックでの該当ページ遷移に対応しています。
  - **通知プラグイン**（既定で無効）：選択したイベントをスマホやチャット（ntfy・Bark・Feishu・DingTalk・Telegram・Slack など）へ送信できます。API キー・プロンプト・ヘッダーは含まれず、シークレットのマスク保存、「保存してテスト送信」、「最近の送信履歴」の確認に対応しています。
- **内蔵「スズメ」テーマ**：「シンプル」テーマをベースに、温かみのあるクリーム色の背景とジンジャーオレンジのアクセント色を採用した「スズメ」テーマを追加しました（リアルタイムルーティングの進行中トラフィックは水色）。「設定 → 一般 → 外観」またはサイドバーから切り替えられ、初回オンボーディングにも「シンプル」と「スズメ」のプレビューを追加しています。
- **利用レシート設定の統一とバーコード既定化**：「フッターコード」とコンパクト表記がすべてのレシートテーマに適用され、表示モード・「キャッシュ token を表示」・リクエスト数がクラシックテーマとプラグインレシートの双方に効くようになりました。一部プラットフォームで共有画像内の QR コードがブロックされるのを防ぐため、「フッターコード」の既定を「バーコード」に変更しています。

## 修正
- **デスクトップ版の確認ダイアログが応答を待たずに実行される不具合**：デスクトップ版で一部の確認操作（プラグインのアンインストール、HTTPS 証明書の再生成、エージェント監視の接続設定削除、サブスクリプション累計上限のリセット、設定エディタの未保存変更破棄、Web 認証・プロキシ再起動の確認）が確認ダイアログの選択を待たずにそのまま実行されてしまう問題を修正しました。
