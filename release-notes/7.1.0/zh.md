这个版本推出「Sparrow Bakery · 麻雀面包坊」插件中心，完整支持界面主题、小票主题、厂商、计价、规则与通知六类纯数据插件；同时新增内置系统桌面通知、内置「麻雀」主题、订阅按新描述重建连接，并统一用量小票展示设置。升级后默认行为基本不变（仅用量小票底部识别码默认改为条形码），系统桌面通知默认关闭，规则与通知插件安装后默认停用。

## 新功能
- **插件中心（Sparrow Bakery · 麻雀面包坊）**：侧栏新增插件入口，可浏览社区目录、搜索与按分类筛选，并支持「从链接安装」（GitHub 仓库链接并固定到指定提交）与「从文件夹加载」；每个插件均可查看插件介绍页与固定提交的源码。
  - 所有插件只包含数据、不运行任何代码；安装、卸载与启用等管理操作仅限桌面端，网页界面仅支持查看和使用已安装插件；计价与规则插件支持在已安装列表中调整优先级顺序。
- **界面主题与小票主题插件**：支持安装社区或第三方「界面主题」插件（支持安装前「试穿」预览颜色与形状）和「小票主题」插件（安装前用样例数据预览，并支持导出 PNG、PDF 与 HTML）；来自社区的插件会在设置、小票主题选择与插件页显示「社区」标记。
- **厂商插件与订阅重建连接**：支持安装「厂商」插件扩展内置厂商之外的接入源，安装前列出接收 API Key 的域名清单与版本变更对比，并支持声明式 JSON 余额查询；卸载厂商插件后，已有订阅仍凭已存连接信息继续运行。
  - 订阅编辑页新增「厂商描述已更新」提示（内置厂商与插件厂商均适用），可逐字段对比新旧连接差异并一键「按新描述重建连接」。
- **计价插件与费用统计**：支持安装「计价」插件，启用后按当前价格表实时计算历史与单次请求的估算费用，无需重新入库；「数据统计」新增费用卡片、「请求日志」详情展示单次估算费用、插件小票可读取费用字段。
  - 启用计价插件后，订阅编辑页新增「计费方式」（按量付费 / 包月 / 套餐）；包月订阅以「包月订阅的等价费用」单独统计，不计入按量花费，USD 与 CNY 分开展示。
- **规则插件**（安装后默认停用）：支持在路由前（改道到其他虚拟模型或拒绝请求）和发出前（向 system 追加文本、设置或限制采样与思考参数、移除工具定义、脱敏替换文本）对请求生效（不影响 `/v1/systemone`）。
  - 支持动态表单配置参数与基于最近请求日志的「试运行」预览；插件更新时若新增能力或变更参数会自动停用；请求详情中展示命中的规则插件与规则 ID。
- **系统桌面通知与通知插件**（默认关闭 / 安装后默认停用）：新增内置桌面通知与远程推送能力，及时提醒订阅异常、代理停止与每日用量。
  - **系统桌面通知**（默认关闭）：在「设置 → 通用 → 通知」开启，可勾选通知事件（默认勾选订阅鉴权失败、订阅达到限额、代理服务异常停止）并设置「每日汇总时间」（默认 21:00）；同一事件 10 分钟内去重（窗口期内连续「所有候选订阅均失败」会合并计数），支持发送测试通知，点击通知直接唤出主窗口并跳转到对应页面。
  - **通知插件**（默认停用）：支持将选定事件推送至手机或群聊（如 ntfy、Bark、飞书、钉钉、Telegram、Slack 等），推送内容不含 API Key、提示词或请求头；支持敏感凭据脱敏保存、「保存并测试推送」与查看「最近发送记录」。
- **内置「麻雀」主题**：在「简洁」主题基础上新增暖奶油底色与姜橙色强调色的「麻雀」主题（实时路由进行中流量使用水蓝色），可在「设置 → 通用 → 外观」或侧栏切换；同时补齐引导页中「简洁」与「麻雀」主题预览。
- **用量小票设置统一与默认条形码**：「底部识别码」与紧凑数字现在对所有小票主题生效，聚合视图、「显示缓存 token」与请求数对经典主题和插件小票生效；为避免分享图中的二维码在部分平台被屏蔽，「底部识别码」默认改为「条形码」。

## 修复
- **桌面端确认弹窗未等待确认即执行**：修复桌面端部分确认操作（卸载插件、重新生成 HTTPS 证书、清除 Agent 监控接入配置、重置订阅累计配额、放弃配置编辑器未保存修改及网页鉴权与代理重启确认）跳过弹窗等待、直接执行的问题。
