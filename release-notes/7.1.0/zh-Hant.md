這個版本推出「Sparrow Bakery · 麻雀麵包坊」外掛中心，完整支援介面主題、小票主題、廠商、計價、規則與通知六類純資料外掛；同時新增內建系統桌面通知、內建「麻雀」主題、訂閱依新描述重建連線，並統一用量小票顯示設定。升級後預設行為基本不變（僅用量小票底部識別碼預設改為條碼），系統桌面通知預設關閉，規則與通知外掛安裝後預設停用。

## 新功能
- **外掛中心（Sparrow Bakery · 麻雀麵包坊）**：側欄新增外掛入口，可瀏覽社群目錄、搜尋與依分類篩選，並支援「從連結安裝」（GitHub 儲存庫連結並固定到指定提交）與「從資料夾載入」；每個外掛均可檢視外掛介紹頁與固定提交的原始碼。
  - 所有外掛只包含資料、不執行任何程式碼；安裝、解除安裝與啟用等管理操作僅限桌面端，網頁介面僅支援檢視和使用已安裝外掛；計價與規則外掛支援在已安裝清單中調整優先順序。
- **介面主題與小票主題外掛**：支援安裝社群或第三方「介面主題」外掛（支援安裝前「試穿」預覽顏色與形狀）和「小票主題」外掛（安裝前用範例資料預覽，並支援匯出 PNG、PDF 與 HTML）；來自社群的外掛會在設定、小票主題選擇與外掛頁顯示「社群」標記。
- **廠商外掛與訂閱重建連線**：支援安裝「廠商」外掛擴充內建廠商之外的接入來源，安裝前列舉接收 API Key 的網域清單與版本變更對比，並支援宣告式 JSON 餘額查詢；解除安裝廠商外掛後，既有訂閱仍憑已儲存的連線資訊繼續執行。
  - 訂閱編輯頁新增「廠商描述已更新」提示（內建廠商與外掛廠商均適用），可逐欄位對比新舊連線差異並一鍵「依新描述重建連線」。
- **計價外掛與費用統計**：支援安裝「計價」外掛，啟用後依目前價格表即時計算歷史與單次請求的估算費用，無需重新入庫；「資料統計」新增費用卡片、「請求紀錄」詳情顯示單次估算費用、外掛小票可讀取費用欄位。
  - 啟用計價外掛後，訂閱編輯頁新增「計費方式」（按量付費 / 包月 / 方案）；包月訂閱以「包月訂閱的等價費用」單獨統計，不計入按量花費，USD 與 CNY 分開顯示。
- **規則外掛**（安裝後預設停用）：支援在路由前（改道到其他虛擬模型或拒絕請求）和送出前（向 system 附加文字、設定或限制取樣與思考參數、移除工具定義、遮蔽替換文字）對請求生效（不影響 `/v1/systemone`）。
  - 支援動態表單設定參數與基於最近請求紀錄的「試執行」預覽；外掛更新時若新增能力或變更參數會自動停用；請求詳情中顯示命中的規則外掛與規則 ID。
- **系統桌面通知與通知外掛**（預設關閉 / 安裝後預設停用）：新增內建桌面通知與遠端推送能力，及時提醒訂閱異常、代理停止與每日用量。
  - **系統桌面通知**（預設關閉）：在「設定 → 通用 → 通知」開啟，可勾選通知事件（預設勾選訂閱驗證失敗、訂閱達到限額、代理服務異常停止）並設定「每日彙總時間」（預設 21:00）；同一事件 10 分鐘內去重（時間窗內連續「所有候選訂閱均失敗」會合併計數），支援傳送測試通知，點擊通知直接喚出主視窗並跳轉到對應頁面。
  - **通知外掛**（預設停用）：支援將選定事件推送至手機或群組（如 ntfy、Bark、飛書、釘釘、Telegram、Slack 等），推送內容不含 API Key、提示詞或請求標頭；支援敏感憑證遮蔽儲存、「儲存並測試推送」與檢視「最近傳送記錄」。
- **內建「麻雀」主題**：在「簡潔」主題基礎上新增暖奶油底色與薑橙色強調色的「麻雀」主題（即時路由進行中流量使用水藍色），可在「設定 → 通用 → 外觀」或側欄切換；同時補齊引導頁中「簡潔」與「麻雀」主題預覽。
- **用量小票設定統一與預設條碼**：「底部識別碼」與緊湊數字現在對所有小票主題生效，聚合檢視、「顯示快取 token」與請求數對經典主題和外掛小票生效；為避免分享圖中的 QR Code 在部分平台被封鎖，「底部識別碼」預設改為「條碼」。

## 修正
- **桌面端確認彈窗未等待確認即執行**：修正桌面端部分確認操作（解除安裝外掛、重新產生 HTTPS 憑證、清除 Agent 監控接入設定、重設訂閱累計額度、放棄設定編輯器未儲存修改及網頁驗證與代理重新啟動確認）跳過彈窗等待、直接執行的問題。
