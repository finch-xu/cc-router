03

与 v1 的差异与落地方式

视觉改动

  • 中性色：从带紫的灰 #f6f6f8 换成锌灰；暗色底降到 #0f0f11，卡片 #17171a，层级靠 1px 线 + 顶部内高光区分，不再靠大面积灰块。
  • 主色：#aa4935 → #d9573b，主按钮与 Logo 用同色相的 135° 渐变 + 内高光，其它地方仍用纯色。
  • 导航选中态：从黑底白字改为「浮起的白卡片 + 主色图标」，视觉更轻；侧栏按 开始 / 路由 / 观测 / 系统 分组。
  • 代理状态：侧栏底部常驻状态卡（呼吸点 + 端口 + 进行中数），代替导航项上的绿点。
  • 状态 pill：统一「圆点 + 文字 + 同色描边」，6 种语义色，暗色下自动降饱和。
  • 表格：表头浅底、行 hover、选中行左侧 2px 主色条；行内操作 hover 才出现；日志页改成表格 + 右侧详情抽屉的主从布局。
  • 数字：KPI / 耗时 / Token 全部 tabular-nums 与等宽字体，滚动刷新时不跳动。

落地方式（不动组件结构）

  • src/themes/quiet.css：替换两段配色 token（浅色 / .dark），同步 shadcn 的 HSL 变量。
  • 新增 --surface-glass --grad-accent --ring --dur-*，只在 [data-theme="quiet"] 下定义，不影响经典 / Win2000。
  • 外形规则写在 quiet.css 的 @layer utilities，沿用 :where([data-theme="quiet"]) 不加权重的写法：.nav-item.active、.btn.primary、.pill、.table th/td、.card 阴影。
  • 侧栏分组标题与底部状态卡需要改 Sidebar.tsx（按 themeId === "quiet" 渲染），新增文案四语齐全。
  • 日志主从布局、KPI 迷你折线是页面级改动，建议作为第二步单独做。
  • 动效全部 ≤ 280ms、可打断；呼吸点是唯一循环动画（表示「运行中」），尊重 prefers-reduced-motion。
