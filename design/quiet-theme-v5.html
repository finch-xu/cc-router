与现在「简洁」的差异

  • 侧栏选中：黑底白字 → 浅灰底；条目按「路由 / 观测 / 系统」留白分组，不加标题。
  • 页面大标题 + 副标题 → 48px 顶栏小标题；页内 tab（日志、设置、指南）并进顶栏。
  • 卡片、表格外框、行分隔线、虚线框全部去掉，行靠悬停底色。
  • 状态彩色胶囊（「● 失败」「401」）→ 圆点 + 灰字 + 等宽状态码。
  • 路由图：彩色虚线 / 便签 → 灰色细线，有流量的连线才加深。
  • 虚拟模型：红色 503 警告框 → 圆点 + 一行灰字；星期色块统一灰阶。
